### AI coding and agent evaluation focus

- **Code quality:** review generated Python/JavaScript solutions for logic errors, unsafe assumptions, API contract mismatches, and reproducible bugs.
- **Multi-step tool use:** trace agent decisions, function parameters, state transitions, approvals, and recovery behavior against task requirements.
- **Evaluation datasets:** develop edge cases, regression scenarios, and explicit review criteria for identifying model failure patterns. Curated examples and human ratings are useful training signals **when included in a training or feedback process**; evaluating a model does not itself change its weights.

This focus builds on developer experience and personal agent-system projects, rather than a claimed history of paid model-evaluation contracts.
